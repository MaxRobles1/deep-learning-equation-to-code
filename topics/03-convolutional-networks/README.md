# Tema 3 · Redes neuronales convolucionales (CNN)

## Objetivos
Al terminar este tema podrás explicar qué calcula una convolución y por qué funciona con
imágenes, combinar capas convolucionales, de pooling y totalmente conectadas, y reutilizar
modelos preentrenados mediante transfer learning.

## Prerrequisitos
Temas 1 y 2. Conviene conocer el descenso de gradiente (lección 5.1).
