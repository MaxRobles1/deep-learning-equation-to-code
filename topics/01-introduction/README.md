# Tema 1 · Introducción al aprendizaje profundo

## Objetivos
Al terminar este tema podrás distinguir IA, machine learning y deep learning; explicar qué
hace una neurona artificial y cómo se organizan en capas; y reconocer cómo los
hiperparámetros influyen en el balance entre sesgo y varianza.

## Prerrequisitos
Python básico, álgebra lineal (vectores y matrices) y derivadas.
