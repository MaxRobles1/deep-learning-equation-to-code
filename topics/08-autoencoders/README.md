# Tema 8 · Autoencoders

## Objetivos
Al terminar este tema podrás explicar cómo un autoencoder aprende una representación
comprimida de los datos, distinguir sus variantes, construir autoencoders convolucionales y
usarlos para detectar anomalías.

## Prerrequisitos
Temas 1, 2, 3, 5 y 6.
