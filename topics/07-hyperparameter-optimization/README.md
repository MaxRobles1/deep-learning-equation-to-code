# Tema 7 · Optimización de hiperparámetros (HPO)

## Objetivos
Al terminar este tema podrás diseñar una búsqueda de hiperparámetros con grid search, random
search u optimización bayesiana, separar correctamente entrenamiento, validación y prueba
para evitar la fuga de datos, y automatizar la búsqueda con Optuna.

## Prerrequisitos
Temas 1, 2, 5 y 6.
