# Tema 4 · Redes neuronales recurrentes (RNN)

## Objetivos
Al terminar este tema podrás explicar cómo una red recurrente procesa secuencias, por qué
le cuesta recordar dependencias largas y cómo las arquitecturas LSTM y GRU lo resuelven, y
aplicarlas al análisis de series temporales.

## Prerrequisitos
Temas 1 y 2. Conviene conocer el descenso de gradiente (lección 5.1).
