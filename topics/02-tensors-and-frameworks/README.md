# Tema 2 · Tensores, máquinas de ejecución y frameworks

## Objetivos
Al terminar este tema podrás operar con tensores, explicar cómo un grafo computacional
permite calcular gradientes de forma automática, ubicar a PyTorch dentro del ecosistema de
frameworks y construir tu primer modelo en PyTorch con seguimiento en TensorBoard.

## Prerrequisitos
Tema 1 y Python con NumPy.
