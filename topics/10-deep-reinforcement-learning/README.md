# Tema 10 · Aprendizaje por refuerzo profundo (Deep Reinforcement Learning)

## Objetivos
Al terminar este tema podrás modelar un problema como un proceso de decisión de Markov,
implementar Q-learning y extenderlo con una red neuronal (Deep Q-Network), y reconocer
aplicaciones del aprendizaje por refuerzo profundo.

## Prerrequisitos
Temas 1, 2 y 5, y probabilidad básica. Las cadenas de Markov se introducen en la lección 10.1.
